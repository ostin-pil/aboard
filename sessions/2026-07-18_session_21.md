## What happened

### 1. Verified the competition's live requirements

Re-checked the competition page and the actual Google Form (the plan's facts were
a week old). Key finding that shaped the deliverable: **there is no file upload**
— the required field 9 ("Primary Document or Drive URL") wants a *link* (Google
Doc, Drive, site, or video). Deadline confirmed 2026-07-19, no time given.

### 2. Hosted submission page at `/submission`

Chose to host the writeup on the live site itself rather than a Google Doc or a
Drive PDF. A self-contained static page in `public/submission.html` (copied to
`out/` at build), styled to the site's warm-stone palette with the external-anchor
result as an accented callout and a nav bar linking back into the product (Graph,
About, API, Schema). Rendered from `research/flf-epistack-submission.md` via
`marked` (internal draft note stripped). Deployed with `wrangler deploy`; verified
live (200, `text/html`).

Clean-URL note: right after deploy, `/submission` 404'd for a few seconds while
`/submission.html` already 307'd to it — edge propagation, not a routing bug. It
resolved on its own. The Worker passes everything except `POST /api/proposals`
straight to the assets binding, so clean URLs are Cloudflare's default handling.

### 3. Hosted PDF at `/submission.pdf`

Built a 3-page print render (Chrome headless `--print-to-pdf` over a print-styled
HTML) and hosted it at `/submission.pdf` (`application/pdf`), linked from the page,
as a portable backup.

### 4. Drafted the form answers; entry submitted

Provided copy-paste values for every field. Recommendations: submission type
**Prototype tool / pipeline** (not the plan's earlier "comparative analysis" — the
agent write path went live since then, so aboard is now a running system), layers
**All / integrated** (structure + assessment; no two-layer option). Maintainer
filled the personal fields (name, bio, "interest in further paid work") and
submitted.

## Decisions worth remembering

- **Primary Document = the live site, not an external doc.** On-thesis
  ("already running"), a permanent URL under our control, and it doubles as the
  public artifact funding applications need (per `plans/flf-epistack-entry.md`).
- **Static file in `public/` over a Next route.** Sidesteps the app's strict
  TS/Next constraints and the missing markdown renderer, and deploys through the
  same proven pipeline. A focused submission page doesn't need the app's chrome.
