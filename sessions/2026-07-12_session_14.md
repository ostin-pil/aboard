### 6. Cloudflare deploy, debugged (PR #21 + PR #20)

Chose Cloudflare (primary) + Codeberg (mirror). The user set up a CF **Worker**
named `aboard` via the unified Git flow. Three real failures surfaced and were
fixed:
- **Build failed at type-check:** `tsconfig` excluded `clients` but not
  `mcp-server`, so a clean-clone `next build` type-checked `mcp-server/` and hit
  its uninstalled `@modelcontextprotocol/sdk`. Fixed by excluding `mcp-server`;
  verified by hiding `mcp-server/node_modules` and rebuilding (exit 0). This is a
  latent portability bug any CI would hit — it only passed locally because the
  sub-package's `node_modules` existed.
- **Nothing to serve:** the Worker had no wrangler config. Added `wrangler.jsonc`
  (`assets.directory: ./out`) so `npx wrangler deploy` serves the static export.
- **Malformed `@id`s:** the `SITE_URL` build variable had a trailing space,
  producing `https://aboard.ostin-pil.workers.dev /graph`. Hardened
  `siteBaseUrl()` with `.trim()` so dashboard whitespace can't break it.

Result: **live at https://aboard.ostin-pil.workers.dev**; `/api/graph`,
`/api/claims/ECM1`, `/api/claims/M4` all validate against `v0.json`; content-types
correct via `_headers`; eggs dossier renders correctly (verified visually).

## Decisions worth remembering

1. **Narrow the thesis.** Drop "agent-first" and "forecasting" as differentiators
   (both commoditized/occupied by 2026). The defensible core is the cross-domain
   causal claim graph + radical provenance + dual-dossier-with-ranked-cruxes,
   published machine-readably. The real risk is no consumer (QURI/AIF graveyard),
   not a competitor.
2. **aboard is now a static site** (`output: "export"` → `out/`), deployable
   anywhere with no lock-in. The build **must** set `SITE_URL` for absolute,
   schema-valid JSON-LD `@id`s; unset yields relative IRIs (valid JSON-LD, fails
   `v0.json`'s strict `uri` format).
3. **`tsconfig` must exclude every sub-package** (`clients`, `mcp-server`) or a
   clean-clone / CI / Cloudflare build fails at type-check. Latent, not new.
4. **CF Worker static deploy needs `wrangler.jsonc`** (`assets.directory: ./out`);
   `_headers` handles the extensionless content-types + CORS.
5. **The agent cannot self-grant permissions or repoint remotes in auto mode** —
   deliberate guards; those steps are the user's.
