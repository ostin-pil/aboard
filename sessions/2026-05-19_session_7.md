### 4. The collapse-bug saga (resolved)

User reported the domain-group header "starts the drag" / no hover / no
click — a complaint spanning several prior sessions. The Track B agent
was resumed ~6× (concurrently with the branch surgery — risky, only
safe because the primary worktree happened to be on `track-b-editor`).
Diagnostic arc:

- My theory: RF d3-zoom eats pointerdown → `nodrag nopan` on the header
  (`305347f`). Correct as defense-in-depth, not the actual blocker.
- Agent's better root cause (verified statically): the **`.ag-row-label`
  from B's own Task-2 row-labels (`b9bd2fe`) is `position:absolute` +
  opaque `background` + no `pointer-events`**, transform-translated
  directly over the group-header strip — it swallowed every pointerdown.
  A pointerdown on that non-interactive label inside the RF pane → pane
  pan, i.e. exactly "starts the drag." Fix: `pointer-events:none` on
  `.ag-row-label` (`f0c71ba`).
- The console-trace confirmation loop failed: the user's paste arrived
  to the agent as an empty placeholder three times (chat-channel
  transmission issue, not code). Decision: **ship on static proof** —
  the regression is provable from committed CSS and an independent CSS
  audit found no other header overlay; the dual fix
  (`pointer-events:none` + `nodrag/nopan`) covers the residual case.
  Browser check deliberately skipped per maintainer call (long session).
  All `ag-dbg` instrumentation stripped before the clean commit.

## Decisions worth remembering

1. **Worktree isolation can still land on local `main`.** Brief agents
   accordingly and verify per-commit scoping; don't assume isolated
   branches. The non-overlapping file-ownership partition is what made
   recovery trivial — keep that discipline for any parallel agents.
2. **Don't resume background agents mid-orchestration.** ~6 concurrent
   resumes of Track B while branch surgery was in flight caused
   thrash; it only stayed safe by luck (primary worktree happened to
   be on the right branch). Single controller, sequence the work.
3. **Ship on static proof when the empirical channel is broken** and
   the root cause is provable + independently audited. Endured ~5
   broken paste loops before making this call; should have made it
   sooner. Validated by the maintainer ("skip the header check").
4. **The F4 thesis framing is "spread/outlier," not "median reversal."**
   Spread 0.02→0.25 from one dissenter; A=false-consensus /
   B=outlier-dominance. Do not paraphrase it as a median move — that
   was this session's self-inflicted scare.
5. **Absolutely-positioned opaque child of a `pointer-events:none`
   panel still eats pointers.** Needs explicit `pointer-events:none`
   on the child. This pattern caused the multi-session collapse bug.
6. **Per-track PR disentanglement recipe** (if it recurs): branch each
   track off the merge-base, cherry-pick its commits, amend shared-file
   commits to move mis-attributed hunks, build-gate each, reset local
   `main` only after all branches verified.
