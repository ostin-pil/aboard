## Decisions worth remembering

- **`rel=alternate` via metadata, not an `_headers` Link header.** Per-page
  response headers aren't guaranteed under `output: "export"`, and the Worker
  ASSETS `:id` value-interpolation was uncertain, so a wrong literal `:id` would
  be worse than none. An HTML `<link rel="alternate">` is guaranteed correct and
  is arguably better-parsed than an HTTP Link header. Recorded in
  `agent-surface.md`.
- **`robots.txt` as a static file, not `app/robots.ts`.** Next's typed
  `MetadataRoute.Robots` can't express Content-Signal lines. The static file is
  exempt from `canonical-urls.test.ts` (which only scans `src/**`), so hardcoding
  the canonical origin in its `Sitemap:` line is fine; every `src/` surface uses
  `siteBaseUrl()`.
- **The crawler block lived in the Cloudflare dashboard, not the repo.** An
  in-repo `robots.txt` alone would not have unblocked crawlers and could have been
  shadowed by the managed file — the dashboard toggle was the actual fix.
- **About-page counts are now derived from the graph.** The drift that put "20
  seed claims" against a real 24 is the failure this prevents.
- **Markdown twins are a bonus** beyond `agent-surface.md`, cheap because claims
  are already Markdown-native.
- **Branch renamed** `feat/discovery-surface` → `feature/session-26-discovery-surface`
  at session end to follow `branch_pattern` before it was pushed.
