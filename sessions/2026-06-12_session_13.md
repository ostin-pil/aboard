## What happened

### 1. Pass 1 — integrity / anti-gaming; diagnosed and fixed the verify cliff

The session-12 run's verifier had crashed on ~19/25 claims (logged as
`0-0 abstain`). Reading the prior run's transcripts showed the cause was **not**
"model writes prose instead of StructuredOutput" but a **rate-limit cliff**:
104×`429` + 53×`rate_limit` in the logs, concentrated in the verify phase's
burst of concurrent WebSearch calls (every voter ran one). Fix: a patched fork
that **removed WebSearch from verify** (text-mode voting + a parser). Result:
**18/18 confirmed, 0 abstains, ~25 min** (vs 76% abstain, 91 min). Honest
trade-off: no web access makes verify reliable-but-lenient (0 killed), so the
real adversarial work shifted to the synthesis agent's calibration rule + manual
spot-checks. Findings: the external-anchor thesis (every gaming-resistant defense
terminates outside the graph), CIDRE citation-cartel detection, Metaculus proper
scoring (only works with external resolution), Polymarket manipulation
(incomplete self-correction), Wikipedia human-gated bot approval (BAG). Doc:
`research/integrity-anti-gaming.md`.

### 2. Pass 2 — Sybil/identity gap-fill; failsafe hybrid verify

To fill the gaps (Sybil/identity/web-of-trust/oracle) AND regain external-evidence
checking without the cliff, built a **failsafe hybrid verify**: per claim, 1
WebSearch voter (catches fabricated sources) + 2 reason-only voters. Key property:
if the web voter 429s it abstains, and the 2 reason voters still meet quorum — so
the abstain-cliff **cannot** recur; worst case degrades to reason-only. Result:
**19/25 confirmed, 6 genuinely refuted, 0 abstain-kills** — real adversarial
quality (the web voter refuted six overreaching claims). BUT the run took **~9
hours / ~1.87M tokens** under heavy throttling (third large run of the day,
~4.5M total), and the throttling hit the **fetch** stage, dropping the
named-system sources. Findings: Douceur's Sybil impossibility (no internal-only
defense works), the Decentralized Identity Trilemma, ERC-8004 per-agent identity,
the Human Challenge Oracle (human anchor is fragile to advancing AI),
Polymarket/UMA stake-adjudication failures. Doc: `research/sybil-identity.md`.

### 3. Pass 3 — direct-fetch to close the named-system gaps

Rather than a fourth throttled workflow run, used **3 targeted WebSearch calls**
(cheap, no workflow) to close the named-system gaps: proof-of-personhood systems
(World ID / BrightID / Proof of Humanity / Gitcoin-Human Passport, and the
**tiered-PoP** pattern — light Sybil score escalating to strong PoP for
high-impact, which softens the throughput-vs-integrity tension), trust-propagation
failure modes (EigenTrust white-washing; social-graph metrics' assumption-
dependent bounds), and incentives (Manifold mana resists Sybils *emergently* via
non-cashability; Stack Overflow cumulative reputation-gating; ResearchHub RSC is
cashable → reintroduces the gaming incentive). Folded into `sybil-identity.md`
(tagged medium-confidence: search-surfaced, not 3-vote verified).

## Decisions worth remembering

1. **The deep-research verify stage is rate-limit-fragile.** Its failure mode is
   a temporal cliff (first N claims OK, then sustained 429s), logged as
   `0-0 abstain` and easily misread as "claims refuted." Always reconcile abstain
   (not tested) vs real refutation before trusting a "weak/risky" conclusion.
2. **The failsafe hybrid verify is the reusable fix.** 1 WebSearch voter + 2
   reason-only voters: regains external-evidence + source-existence checking while
   guaranteeing quorum from the reason voters, so a 429 can never re-trigger the
   abstain-cliff. Worth upstreaming into the deep-research workflow.
3. **The verify fix made runs reliable, NOT cheaper.** Tokens rose across passes
   (1.05M → 1.55M → 1.87M; ~4.5M total). The third run hit ~9h wall-clock under
   throttling. Reliability and cost are separate axes; report both honestly.
4. **Verify confabulation-prone citations by hand before committing** (oddly
   specific stats, recent arXiv IDs). CLAUDE.md mandates real source URLs.
5. **The through-line for aboard:** integrity, adjudication (Q2), and
   Sybil-resistance are the SAME problem — every gaming-resistant defense
   terminates in an external, real-world anchor outside the agent graph. That is
   aboard's clearest design constraint and its sharpest tension with the
   agent-first high-throughput vision.
